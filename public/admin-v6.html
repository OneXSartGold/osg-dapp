In order, one step at a time. Each line shows what the chain says now; a button appears only when the steps before it are done. Every step is tested first.

1. Load the v5 snapshot

Choose the JSON file saved by admin v5 (Members tab, "Referral v6 migration: v5 snapshot"). The page checks it and builds every batch.

2. Amoy only: copy chain state into the test contracts

Writes each wallet's old Active staking bond and its Term/LP stake into the test stand-ins, so seeding is checked against the same data as Polygon.

Load the snapshot first.

3. Seed batches

Send them in order. "Check all" reads the chain and marks finished batches. A batch that is already on the chain is skipped by "Send next".

Load the snapshot first.

4. Final check and launch

Totals on the chain must equal the snapshot. Lock seeding only when every line is green. Locking cannot be undone.
